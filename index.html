Usability Evaluation of Ruangguru Online Learning Mobile Application Using Heuristic Method

The 9th International Conference on Computer Science and Computational Intelligence, 2024

Authors: Hardi Kusuma, Fulgencia Shaynalie Rue, Reinert Rumagit, Galih D Pratama

Evaluates the usability of the Ruangguru online learning mobile application using the heuristic evaluation method. By assessing the interface against established usability principles, the study identifies strengths and weaknesses in navigation, user feedback, and error prevention, aiming to inform future improvements and support better learning outcomes for students.
